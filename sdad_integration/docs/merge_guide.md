# 与Xu的整合说明

## 三代关系

| 方法 | 内容 | 整合来源 |
|---|---|---|
| 第一代 | 仅正常组、无蒸馏、无高低组混合 | Xu |
| 第二代 | 固定比例混合、时空融合、同步蒸馏 | Xu |
| 第三代SDAD-Net | 时空融合与蒸馏基础上的后期高低组DANN | 本包 |

本包保留的是第三代的实验实现和前期探索，不含已验证的统一三代训练入口。旧小车历史实现不能直接标成Xu第一代或第二代。

## 合并顺序

1. 以Xu整理分支为团队整合基础，记录双方提交版本。
2. 将本文件夹作为独立SDAD模块加入，不覆盖团队的`src/`和GUI。
3. 保留本包`code/src/plan_a`等依赖，先验证已有模型可加载。
4. 核对11通道与团队通道配置、采样率、标签、CSP、标准化及数据划分。
5. 分别保存三代模型的配置、预处理和实验结果，不直接串接不兼容权重。
6. GUI完整使用Xu原版，不接入新增模型适配；SDAD保持独立入口，硬件链路在hardware_legacy中保留。
7. 完成短流程与加载检查后，通过Pull Request审核；不要求重新长时间训练。

## 不自动替换的内容

- 本包学生／教师结构和预处理：受历史源码指纹与检查点约束。
- 实验固定25人分组及训练／验证／测试协议。
- 早期A/B、对齐、加权和诊断记录：保留分类，不混入正式结果。
- 外部权重与结果：先核对来源与校验值，再决定纳入位置。

同名公共功能最终以Xu为主，但必须在兼容性核对后接入。本阶段没有改动Xu仓库、没有提交或推送。
